# Support

This repository accepts reproducible bug reports about the Azure App Service experience in the Azure portal.

## Use GitHub Issues for

- Portal pages or workflows that fail to load or behave incorrectly
- Incorrect, missing, or confusing behavior in the App Service portal experience
- Reproducible accessibility or usability defects

Use the repository's structured bug report form and provide enough information for the team to reproduce the problem. Remove secrets, tokens, personal information, subscription IDs, resource IDs, and resource names before submitting.

## Use Azure Support for

- Production incidents or service outages
- Account, subscription, quota, or billing assistance
- Resource-specific troubleshooting that requires sharing private identifiers or logs
- Time-sensitive or SLA-backed support

[Create an Azure support request](https://azure.microsoft.com/support/create-ticket/).

## Report security vulnerabilities privately

Do not report security vulnerabilities in a public GitHub issue. Follow [SECURITY.md](SECURITY.md) to contact the Microsoft Security Response Center.

GitHub issues in this repository do not have a guaranteed response time and are not a substitute for Azure Support.
