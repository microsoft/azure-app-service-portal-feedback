# Azure App Service portal feedback

This repository is the public issue tracker for bugs in the Azure App Service experience in the Azure portal. The product source is maintained privately and is not published here.

## File a bug

Use the [bug report form](https://github.com/microsoft/azure-app-service-portal-feedback/issues/new?template=bug_report.yml) for reproducible problems with the Azure App Service portal experience.

Before filing:

- Remove secrets, access tokens, personal information, subscription IDs, resource IDs, and resource names.
- Search existing issues to avoid duplicates.
- Include clear reproduction steps, the approximate time and time zone, browser details, and any correlation or request ID that is safe to share.

## Support boundaries

GitHub issues are not an Azure Support channel and do not provide guaranteed response times.

- For production incidents, service outages, billing, account or subscription help, or SLA-backed assistance, [create an Azure support request](https://azure.microsoft.com/support/create-ticket/).
- For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and report them privately to the Microsoft Security Response Center.

See the [Azure App Service documentation](https://learn.microsoft.com/azure/app-service/) for product guidance.

## Issue handling

The team reviews new reports regularly. Reports may be closed when they are duplicates, outside this repository's scope, lack enough information to investigate, or require Azure Support.
